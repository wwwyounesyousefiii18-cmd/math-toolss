# Math Tools

برنامه اندرویدی ماشین‌حساب و کوییز (Kivy). ساخت APK به‌صورت خودکار با GitHub Actions.

## دریافت APK
1. تب **Actions** ← آخرین اجرای «Build Android APK» ← بخش Artifacts ← `mathtools-apk`
2. یا با ساخت تگ `v1.0.0` فایل APK در بخش **Releases** منتشر می‌شود.

## اجرا روی کامپیوتر
    pip install kivy
    python main.py
